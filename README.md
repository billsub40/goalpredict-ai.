# goalpredict-ai.

A static football analytics demo for estimating goal markets and match outcomes from average goals scored and conceded.

## Run locally

Open `index.html` in a browser, or serve the repo with a simple static server.

## Features

- Match analyzer with team inputs
- Poisson-based goal estimate
- Goal market probabilities for over 1.5 / 2.5 and both teams to score
- 1X2 win/draw/away probabilities
- Demo-only statistical estimates
